# launCHF – Downloads

launCHF («launch» + «CHF») ist die Buchhaltung für frisch gegründete Schweizer Firmen:
doppelte Buchhaltung in Klartext, QR-Rechnungen mit Bankabgleich, Lohn, Jahresabschluss.
Alles läuft lokal auf dem eigenen PC – keine Cloud, kein Konto.
Deutsch, English, Français, Italiano. Website: [launchf.ch](https://launchf.ch)

## Download

**[launCHF für Windows herunterladen](https://github.com/LabVenturesSG/launchf-releases/releases/latest/download/launchf-portable.zip)** (ZIP, ca. 78 MB)

Alle Versionen und Änderungen: [Releases](https://github.com/LabVenturesSG/launchf-releases/releases)

## Erster Start

1. ZIP an einen festen Ort entpacken, z. B. `C:\launCHF`.
   Nicht in einen OneDrive- oder Dropbox-Ordner – die Datenbank verträgt keine Cloud-Synchronisierung.
2. Doppelklick auf `Start-launCHF.bat`. Beim ersten Start dauert es etwa eine halbe Minute,
   danach öffnet sich die Ersteinrichtung im Browser.
3. Firma, Bankverbindung, E-Mail-Versand, Backup-Ordner und Startkapital eintragen. Fertig.

Eine ausführliche Kurzanleitung in vier Sprachen liegt als `README.txt` im ZIP.

## Updates

launCHF prüft selbst auf neue Versionen. Erscheint ein Hinweis, genügt unter
Einstellungen ein Klick auf «Update installieren». Die Buchhaltungsdaten bleiben dabei unberührt.
